# Pre-Mortem — AI Startup Red-Team Analyzer

A structured interrogation of your idea before the market gets to it.

## What it does

Pre-Mortem takes your startup idea and runs an adversarial analysis identifying the 5 most likely failure modes before you build. Specific ranked risks. No applause.

## Features

- AI-powered red-teaming using GPT-4o
- Case file UI with intelligence-briefing aesthetic and animations
- Persistent reports saved to Supabase with unique slug
- Full-stack React frontend + Express backend

## Tech Stack

- Frontend: React 18 + TypeScript + Vite + Framer Motion
- Backend: Express.js + TypeScript + Node.js
- Database: Supabase (PostgreSQL)
- AI: OpenAI GPT-4o
